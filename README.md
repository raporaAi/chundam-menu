# chundam-menu

춘담(春談) QR 메뉴판. 언어별 QR이 각 경로로 연결되고, 해당 언어로 모바일용 메뉴를 보여준다.

| 언어 | 경로 |
|---|---|
| 일본어 | `/ja` |
| 영어 | `/en` |
| 중국어 | `/zh` |

`/`로 들어오면 브라우저 언어로 자동 분기한다(일본어·중국어 외에는 영어). 하단 바에서 언어를 바꿀 수 있다.

## 메뉴 수정

- 가격·메뉴명·소개 문구: `menu.js` 하나만 고친다. 세 언어가 한 항목에 같이 들어 있다.
- 음식 사진: `menu/dishes/<photo>.webp`를 같은 이름으로 교체한다. `photo` 값이 파일명이다.
- 새 메뉴 추가: 해당 섹션 `items`에 항목을 하나 넣고 사진을 `menu/dishes/`에 추가한다.

push하면 Vercel이 자동 배포한다.

## 구조

빌드 없는 정적 사이트. `index.html`이 경로를 읽어 언어를 정하고 `menu.js` 데이터로 화면을 그린다. `vercel.json`의 rewrite가 `/ja`·`/en`·`/zh`를 `/`로 보낸다.

사진은 원본 인쇄 메뉴판 이미지에서 잘라낸 것이고, 세 언어가 같은 사진을 공유한다.

## QR 코드

`qr/` 폴더에 언어별 QR이 있다(`qr-ja`, `qr-en`, `qr-zh`, 각각 SVG·PNG). 주소가 QR 안에 직접 들어 있는 정적 QR이라 외부 서비스 종속이 없다. 인쇄는 SVG를 쓰고, 세 QR 옆에 日本語 / English / 中文 라벨을 함께 넣는다.
